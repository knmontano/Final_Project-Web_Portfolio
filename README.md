# 🌸 Personal Web Portfolio

A modern, responsive personal web portfolio showcasing my creative graphic design works, software development projects, and academic milestones. Built with a soft, cozy aesthetic and optimized for seamless viewing.

🔗 **Live Website:** [https://knmontano.github.io/Final_Project-Web_Portfolio/](https://knmontano.github.io/Final_Project-Web_Portfolio/)

---

## ✨ Features & Highlights

* **Responsive Design:** Fully adaptive layout optimized for both desktop and mobile viewing.
* **Interactive Elements:** Engaging UI components, smooth transitions, and project modals/lightbox showcases.
* **Curated Projects:** Highlights software engineering applications, interactive simulations, and creative visual design campaigns.

---

## 🛠️ Built With

* **Markup & Structure:** HTML5
* **Styling & Layout:** CSS3, Flexbox, Grid
* **Interactivity:** JavaScript (Vanilla JS)
* **Hosting & Deployment:** GitHub Pages
